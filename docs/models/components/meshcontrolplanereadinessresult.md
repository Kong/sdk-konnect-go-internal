# MeshControlPlaneReadinessResult

What the scan found, and null when the scan produced nothing to report. A scan that could not read the whole estate produces no result rather than a partial one. The checks belong to the Kong Mesh upgrade readiness tool, and this API restates its document in Konnect field names rather than passing it through. The address the scan connected to is deliberately left out, because it names shared infrastructure the reader does not own.
