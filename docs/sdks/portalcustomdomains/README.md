# PortalCustomDomains
(*PortalCustomDomains*)

## Overview

APIs related to configuration of Konnect Developer Portals custom domains.

### Available Operations

* [MigratePortalCustomDomain](#migrateportalcustomdomain) - Migrate Custom Domain

## MigratePortalCustomDomain

Initiates the migration of a portal's custom domain to the new domain management zone. This operation is only allowed for portals currently using a custom domain and that have not yet started the migration process. As part of the migration, DNS records must be updated to point to the new CNAME target. The response includes both the previous (migrating_from) and the new (migrating_to) custom domain information.

### Example Usage

```go
package main

import(
	"context"
	sdkkonnectgointernal "github.com/Kong/sdk-konnect-go-internal"
	"github.com/Kong/sdk-konnect-go-internal/models/components"
	"log"
)

func main() {
    ctx := context.Background()

    s := sdkkonnectgointernal.New(
        sdkkonnectgointernal.WithSecurity(components.Security{

    res, err := s.PortalCustomDomains.MigratePortalCustomDomain(ctx, "f32d905a-ed33-46a3-a093-d8f536af9a8a")

        // handle response
    }
}
```
